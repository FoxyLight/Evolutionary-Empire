# Evolutionary Empire

An incremental evolution game inspired by the progression loop of classic idle games.

## Version 0.1: The Petri Dish

The first prototype focuses on the smallest playable loop:

- Biomass generates automatically.
- Population grows automatically.
- Biomass can be spent on mutations.
- Mutations improve biomass production and population growth.
- Progress is saved automatically in the browser.

## Development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Then open the local Vite development URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```
